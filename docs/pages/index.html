Compile PHP to native binaries

php-compiler parses PHP to a CFG, runs a VM, JIT-compiles with LLVM 9, and links AOT executables for CLI and web — deployed apps need no Zend at runtime. Active work: self-host — the compiler compiling its own lib/ ([#1492](https://github.com/PurHur/php-compiler/issues/1492)).
