Compile PHP to native binaries

php-compiler lowers PHP to a CFG, executes on a VM, JIT-compiles with LLVM 9, and links AOT native executables for CLI and web — deployed apps run without Zend PHP at runtime. Active work: reference web app (MiniWebApp) and self-host bootstrap (compiler compiling its own lib/).

Try it in five minutes

Clone the repo on a Linux host with PHP 8.1+ and Composer. Full presenter script: docs/GETTING-STARTED.md.

1

Fast CI smoke

composer install
./phpc test --fast

VM/compliance gate — no LLVM link required.

2

Native binary

./phpc build -o /tmp/hello \
  examples/000-HelloWorld/example.php
/tmp/hello

PHP source → standalone executable.

3

Web app (VM)

./phpc serve examples/003-MiniWebApp
# → http://127.0.0.1:8080/

Router, templates, forms, JSON API — stable today.

+

Self-host smoke

script/apply-patches.sh
make bootstrap-selfhost-link

Expect compiler_minimal bundle OK (experimental).

Honest scope: not full Zend PHP — subset compiler with generated capability matrices. MiniWebApp AOT execute is partial (home route ✅); VM path is the reliable demo.
