Where we are on the road to a full PHP compiler

php-compiler compiles PHP to an internal CFG, runs it on a VM, JIT-compiles hot paths with LLVM, and can deploy AOT native binaries for web apps — without requiring Zend PHP at runtime for deployed apps.

quick-start.sh 
# Host PHP builds; deployed app runs natively
<?php
composer install

./phpc test                 # + LLVM JIT/AOT
./phpc build --project my-app
./phpc serve examples/003-MiniWebApp

# Self-host (experimental): compile a lib/ bundle with itself
make bootstrap-selfhost-link   # → compiler_minimal bundle OK
