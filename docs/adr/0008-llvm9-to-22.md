# ADR: LLVM 9 now → 22 via pointee threading (#36402)

- Status: Accepted
- Date: 2026-09-04
- Parent: #36402 · related #174 / #36220 · `docs/roadmap/LLVM22-MIGRATION.md`

## Decision

1. **Production / pinned image today:** LLVM **9** (`.llvm/` or
   `PHP_COMPILER_LLVM_PATH`; `script/install-llvm9.sh`).
2. **Migration path:** generate FFI bindings against LLVM 22 headers and thread
   pointee types so the same PHP bindings build on LLVM 9 and 22 (#36220 Phase 0).
3. Do not land opportunistic LLVM 22-only APIs on master until Phase 0 proves the
   binding.

## Why

- The compiler’s MCJIT / pass-manager stack is validated on LLVM 9.
- A flag-day jump without pointee threading breaks every harness host at once.

## Consequences

- Darwin AOT waits on LLVM 22 ([36391](36391-aarch64-darwin-deferred.md)).
- Pass-manager / assert patches stay idempotent (`script/apply-patches.sh`).
