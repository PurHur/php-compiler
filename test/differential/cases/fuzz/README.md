# Fuzz seed corpus (#36398)

Programs generated by `script/fuzz/gen.php` with fixed seeds. Kept as a differential gate so the generator cannot silently drift into unsupported shapes.

```bash
script/differential-sweep.sh --dir test/differential/cases/fuzz
script/differential-sweep.sh --aot --dir test/differential/cases/fuzz --repeat 3
```

New unique fuzz failures (after reduce) land here once fixed — see `script/fuzz/README.md`.
